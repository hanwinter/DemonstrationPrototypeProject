一、新增“家长报名设置”

在“体检计划配置”页面中增加一个独立配置区域：

标题：
家长报名设置

建议放置在体检计划基础信息之后、“基础体检项目”之前。

不要使用独立大卡片，通过标题 + 表单字段 + 适当留白与下方内容形成层级，与当前页面简洁风格保持一致。

二、配置字段

1. 是否开启家长报名

字段：
家长报名：

使用开关组件。

状态：
- 开启
- 关闭

Mock数据默认：
开启

规则：
- 开启后显示报名时间及报名入口相关内容；
- 关闭后不开放该计划的家长H5报名入口。

2. 报名时间

将开始时间和截止时间组合成一个时间范围字段：

报名时间：
[ 2026-04-01 08:00 ] 至 [ 2026-04-10 18:00 ]

使用日期时间选择器。

分别对应：
- 报名开始时间
- 报名截止时间

规则：
- 当前时间早于报名开始时间：H5显示“报名未开始”；
- 当前时间处于报名时间范围：允许家长报名；
- 超过报名截止时间：H5显示“报名已截止”，不允许新增报名。

3. H5报名入口

H5报名地址不需要管理员手工输入。

计划发布并开启家长报名后，由系统自动生成报名入口。

页面展示：

报名入口：
[ 复制链接 ] [ 查看二维码 ]

可在旁边弱化展示：
已生成

点击“复制链接”：
模拟复制当前计划H5报名地址。

点击“查看二维码”：
打开二维码弹窗，展示当前计划报名二维码。

二维码弹窗内容保持简单：
- 标题：家长报名二维码
- 二维码
- 体检计划名称
- 学校名称
- 报名截止时间
- 下载二维码
- 关闭

Mock H5地址可使用：
https://demo.example.com/exam/register?planId=20260418

三、关闭家长报名时的处理

当“家长报名”关闭：

- 报名时间字段置灰不可编辑；
- H5报名入口不提供正常访问；
- 页面保留当前配置，不要因为关闭开关而清空报名时间；
- 再次开启后恢复原配置。

家长报名： [开启]

报名入口： [复制链接] [查看二维码]
