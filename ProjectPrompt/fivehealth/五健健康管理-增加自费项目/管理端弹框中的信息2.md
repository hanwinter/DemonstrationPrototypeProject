请基于当前页面现有布局，对“自费订单详情”弹框进行 UI 优化。**本次只调整 UI 样式与信息层级，不修改字段内容、不修改业务逻辑、不新增功能。**

整体风格调整为现代 SaaS 后台常用的“弱标题 + 强内容 + 留白分区”详情页风格，减少传统表单式的粗重视觉效果，使页面更轻、更清晰、更易扫描。

### 一、顶部标题优化

1. 保留弹框标题“自费订单详情”，作为页面唯一一级标题。
2. 标题字号控制在约 `22px`，字重使用 `500`，不要使用过粗字体。
3. 保留右上角关闭图标“×”，样式继续保持轻量、弱化。
4. 标题区域与正文之间适当增加垂直留白。
5. 不增加标题背景色，不增加标题底部分割线。

### 二、分组标题统一降级

当前页面中的以下分组标题：

* 基本信息
* 订单信息
* 自费项目明细
* 支付摘要
* 操作记录

统一降低视觉权重。

建议样式：

* 字号：`15px ~ 16px`
* 字重：`500`
* 字色：中性深灰，例如 `#475569`
* 不使用纯黑
* 不使用 `600 / 700` 粗体
* 不增加左侧色条
* 不增加图标
* 不增加灰色标题背景

分组之间继续通过“留白 + 浅灰色细分割线”进行区分。

分割线建议：

```css
border-color: #E5E7EB;
border-width: 1px;
```

### 三、基础信息和订单信息字段排版优化

继续保留当前两列布局，但调整为统一的 Label-Value Grid。

要求：

1. 每一列内部字段名称统一宽度。
2. 字段名称右对齐。
3. 字段值左对齐。
4. 左右两列之间保持合理间距，不要拉得过开。
5. 每行字段垂直间距统一。
6. 普通字段值取消普遍加粗。

参考视觉：

```text
学生姓名： 林一凡              学校：     实验小学
班级：     三年级2班           家长姓名： 林女士
联系电话： 13800010001
```

字段名建议使用：

* `14px ~ 15px`
* `font-weight: 400`
* 灰蓝色或中性灰，例如 `#64748B`

普通字段值建议使用：

* `14px ~ 15px`
* `font-weight: 400 / 500`
* 深灰色，例如 `#1F2937`

不要所有值都使用粗体。

保留当前表格结构，不改字段。

3. 表格正文使用 `400`。

“自费项目明细”区域应成为页面主要内容区域，但通过表格本身形成视觉中心，不通过加粗标题实现。
