任务：
在五健家长端移动端报名页的“学生信息确认”卡片中增加医保情况选项，并根据医保情况联动基础项目费用与底部操作按钮。

src/views/FiveHealthParentMobile.vue

业务背景：
当前页面是儿童青少年“五健”健康管理家长端移动端演示页。该需求属于“基础筛查报名”流程，不属于推荐加项/自费项目流程。

已确认业务规则：
1. 批次内基础项目是本次筛查固定内容。
2. 家长不能逐项弃选基础项目。
3. 批次可决定基础项目收费策略。
4. 批次外推荐加项由家长自愿选择，并生成独立自费订单。
5. 不要恢复“自费项目必须绑定免费项目/关联免费项目”的模型。
6. 基础报名与推荐加项购买是相关但不同的业务子流程。
7. 基础项目费用变化不能影响推荐加项选择逻辑。

修改目标：
1. 在“学生信息确认”卡片内增加“医保情况”选择。
2. 选项为：
   - 有医保
   - 无医保
3. 选择“有医保”时：
   - 基础项目费用显示为 ￥0
   - 提交按钮保持“确认基础报名”
4. 选择“无医保”时：
   - 基础项目费用显示为 ￥20
   - 底部按钮文案改为“确认并支付￥20”
5. 未选择医保情况时：
   - 不允许确认基础报名
   - 给出轻量提示，例如“请选择医保情况”
6. 推荐加项区域不改变业务逻辑，不把基础项目 20 元并入推荐加项订单。

UI要求：
1. 整个页面 UI 必须与当前五健家长端移动端风格保持统一。
2. 不新增突兀的卡片样式，不增加过多 Icon。
3. “医保情况”建议放在“学生信息确认”卡片底部，作为一个小分组。
4. 推荐分组标题：
   - 费用资格确认
5. 控件使用 Radio 样式或当前页面已有的选项按钮样式。
6. 不使用伪输入框展示不可编辑信息。
7. 字段排版要与“学生姓名、学校班级、联系电话、备注”保持同一视觉体系。
8. 费用结果要清晰但不要抢过页面主按钮权重。
9. 移动端要保证文字不溢出，按钮不换行破版。
10. 底部固定操作区不得遮挡页面内容，保持已有滚动与底部留白规则。

建议页面结构：
在“学生信息确认”卡片中，备注字段之后增加：

费用资格确认
医保情况：有医保 / 无医保
基础项目费用：￥0 或 ￥20
辅助说明：
- 有医保：本次基础筛查项目免费
- 无医保：本次基础筛查项目需支付 20 元

数据与状态建议：
1. 新增响应式状态：
   - insuranceStatus，可选值：'' | 'insured' | 'uninsured'
2. 新增计算字段：
   - baseProjectFee
     - insuranceStatus === 'insured' => 0
     - insuranceStatus === 'uninsured' => 20
     - 未选择 => null 或 0，但提交时需校验
   - baseSignupButtonText
     - uninsured => 确认并支付￥20
     - insured 或默认 => 确认基础报名
3. 提交基础报名时：
   - 若 insuranceStatus 为空，显示提示并中断。
   - 若 insured，按原基础报名成功逻辑执行。
   - 若 uninsured，模拟进入支付/支付成功逻辑即可，不能影响推荐加项订单状态。

不修改内容：
1. 不改推荐加项的选择、支付、退款逻辑。
2. 不改基础筛查项目列表。
3. 不改学生姓名、学校班级、联系电话、备注字段含义。
4. 不改路由。
5. 不改五健智行专案管理相关页面。
6. 不新增正式建设范围外功能。
