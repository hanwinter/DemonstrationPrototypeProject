任务：
修改五健家长端移动端演示页的页面高度与内部滚动方式。

目标文件：
src/views/FiveHealthParentMobile.vue

当前问题：
该页面的手机演示容器高度会随着浏览器窗口高度变化，桌面预览时手机比例不稳定。截图中的登录页在浏览器变高后被拉得过高，不符合移动端演示页应固定手机视口的要求。

修改目标：
1. 桌面演示态下，手机壳固定为真实手机比例。
2. 内容超出时只在手机壳内部滚动，不让外层页面随内容或浏览器高度变化。
3. 滚动条样式参考项目中已有移动端样式，优先参考：
   src/views/FiveHealthZhixingParentH5.vue 中 `.phone-content` 的滚动条样式。
4. 不修改页面业务内容、文案、字段、按钮、路由和交互逻辑。

具体要求：
1. `.parent-demo`
   - 作为桌面演示背景与居中容器。
   - 保持整页不滚动。
   - 使用 flex 或 grid 将手机壳居中展示。

2. `.phone-shell`
   - 桌面演示态固定宽高。
   - 建议尺寸：`width: 390px; height: 844px;`
   - `max-height` 可兼容小屏桌面，但不能让页面随着浏览器高度无限拉伸。
   - 保持 `overflow: hidden`。
   - 保持现有圆角、阴影、背景风格。

3. `.phone-content`
   - 改为基于 `.phone-shell` 内部剩余高度计算。
   - 普通登录后页面：扣除顶部栏和底部 Tab。
   - 登录页 `.login-content`：只扣除顶部栏。
   - 内容超出时使用内部纵向滚动。
   - 保留已有需要额外底部留白的页面规则，例如报名页、学生管理页、底部固定操作区相关 padding / scroll-padding 逻辑。

4. 滚动条样式
   - 给 `.phone-content` 增加统一滚动条样式：
     - `scrollbar-width: thin`
     - `scrollbar-color: rgba(96,117,124,.18) transparent`
     - `::-webkit-scrollbar { width: 4px; }`
     - `::-webkit-scrollbar-track { background: transparent; }`
     - `::-webkit-scrollbar-thumb { background: rgba(96,117,124,.18); border-radius: 999px; }`
   - 横向滚动区域如专题条、分类标签等，保持现有隐藏或横向滚动样式，不强行显示竖向滚动条。

5. 移动设备/小屏真实预览
   - 保留真实手机访问时的全屏逻辑。
   - 小屏或触屏环境下可继续使用 `100dvh`。
   - 但桌面演示态不能继续使用 `height: calc(100vh - 48px)` 作为最终手机壳高度。
   - 注意文件后部已有多处 `@media` 和 `!important` 覆盖规则，需要统一检查，避免后写规则把固定高度方案覆盖掉。
