继续修改“五健健康管理家长端 H5-专案/儿童建档”页面中的“基础身份信息”分组。

一、修改目标

当前“基础身份信息”字段不完整，需要按照截图中的“基本信息”内容补全字段。

二、字段调整

将“基础身份信息”分组字段调整为以下内容：

1. 档案编号
   - 示例值：MR20260008
   - 只读展示

2. 平台儿保手册
   - 示例值：SXEB20260008
   - 右侧增加“查询”按钮
   - 按移动端样式处理，不要挤压输入框

3. 姓名
   - 示例值：林予安
   - 必填

4. 性别
   - 示例值：男
   - 必填
   - 单选/选择器

5. 出生日期
   - 示例值：2025-01-22
   - 必填
   - 日期选择器

6. 证件类型
   - 示例值：居民身份证
   - 选择器

7. 证件号码
   - 示例值：110101202501221018
   - 右侧增加“查询”按钮
   - 查询按钮样式与“平台儿保手册”的查询按钮一致

8. 国籍
   - 示例值：中国
   - 选择器

9. 民族
   - 示例值：汉族
   - 选择器

10. 户籍类型
    - 示例值：户籍
    - 选择器

11. 户别
    - 示例值：非农业
    - 选择器

12. 现住地址
    - 地址选择部分示例值：北京市 / 市辖区 / 丰台区 / 大红门街道
    - 详细地址示例值：广安路544号
    - 移动端建议拆成两行：
      第一行：省市区街道选择
      第二行：详细地址输入

13. 户籍地址
    - 地址选择部分示例值：北京市 / 市辖区 / 丰台区 / 卢沟桥街道
    - 详细地址示例值：广安路544号
    - 右侧或下方增加“同现住址”操作
    - 点击“同现住址”后，将现住地址的省市区街道和详细地址同步到户籍地址

三、移动端展示要求

1. 保持当前 H5 手机页面宽度，不要变成 PC 表单。
2. 基础身份信息字段较多，移动端不要强行完全两列。
3. 短字段可以两列展示，例如：姓名/性别、出生日期/证件类型、国籍/民族、户籍类型/户别。
4. 带查询按钮的字段建议单行展示，输入框 + 查询按钮横向排列。
5. 地址字段必须单列展示，避免内容挤压。
6. 长地址允许换行，不能超出卡片。
7. 必填字段在字段名前显示红色星号，样式轻量，不要太抢眼。

四、保留逻辑

1. 保留儿童建档页已有的编辑、保存、提交逻辑。
2. 未编辑状态字段只读展示。
3. 点击“编辑资料”后字段可编辑。
4. 不新增弹窗。
5. 不影响下方“就读信息、手册信息、母亲信息、父亲信息、高危信息”的展示。

五、验收标准

1. “基础身份信息”字段与截图中的“基本信息”字段一致。
2. 平台儿保手册、证件号码均有“查询”按钮。
3. 现住地址、户籍地址均包含“地区选择 + 详细地址”。
4. 户籍地址支持“同现住址”。
5. 手机尺寸不变形、不横向滚动、不遮挡底部按钮。
