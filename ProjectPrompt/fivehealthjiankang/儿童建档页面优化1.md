二、阿氏评分逻辑调整

当前页面中同时存在：
“阿氏评分：1分钟 / 5分钟 / 10分钟 / 不详”
以及：
“阿氏评分-1分钟、阿氏评分-5分钟、阿氏评分-10分钟”

这两层逻辑重复，需要调整。

修改为：

1. 去掉“阿氏评分”字段中的“1分钟 / 5分钟 / 10分钟 / 不详”选项按钮。
2. 保留三个独立输入项：
   - 阿氏评分-1分钟
   - 阿氏评分-5分钟
   - 阿氏评分-10分钟
3. 新增一个轻量选项：
   - 阿氏评分不详
4. 当选择“阿氏评分不详”时：
   - 1分钟、5分钟、10分钟三个输入框清空
   - 三个输入框置灰不可编辑
5. 取消“不详”后，三个输入框恢复可编辑。

三、阿氏评分输入规则

1. 三个阿氏评分输入框只允许输入 0-10 的整数。
2. 不允许输入负数、小数、文字或大于 10 的数字。
3. 真实填写状态下默认值建议为空。
4. 如果当前是演示 Mock 数据，可以保留示例值，但不要强制默认全部为 10。
5. 输入框右侧可显示“分”，但不要造成布局拥挤。

   - 隐藏“新生儿听力筛查-未通过”
   - 如原来有填写值，需要清空或不提交该补充字段
