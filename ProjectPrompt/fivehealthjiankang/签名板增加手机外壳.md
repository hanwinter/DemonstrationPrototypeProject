继续优化“五健健康管理家长端H5”的横屏手写签名页。

当前横屏签名页已经改为独立横屏页面，现在需要在签名页外增加一个横向手机外框，用于演示手机横屏签名效果。

要求：

1. 增加横向手机外框
- 在横屏签名页外层增加一个横向手机设备外框。
- 外框比例参考手机横屏，例如 812px × 375px。
- 外框使用浅色或深灰色边框均可，但要保持简洁，不要过重。
- 圆角可以稍大一些，模拟手机机身。
- 内部屏幕区域放置现有签名页内容。
- 可增加很轻的内边距，模拟手机边框厚度。

2. 不要影响签名功能
- 手机外框只作为视觉容器。
- 不要使用 transform: rotate()。
- 不要使用 writing-mode。
- 不要对 canvas 做 CSS 缩放或旋转。
- canvas 坐标仍然基于 canvas.getBoundingClientRect() 计算。
- 鼠标位置和笔画位置必须保持一致。

3. 横屏签名页布局
- 手机外框内部仍按横屏布局：
  - 顶部标题：“请手写家长签名”
  - 中间大面积签名画布
  - 底部按钮：返回、清除重签、确认签名
- 画布要尽量占满屏幕主体区域。
- 按钮不能遮挡画布。

4. 页面背景
- 横屏签名页外部背景可以使用当前系统浅绿色背景。
- 手机外框居中展示。
- 在桌面预览时，横向手机外框应完整显示，不要撑破页面。
- 在移动端小屏幕下，外框可以按比例缩放，但内部 canvas 仍需重新按实际尺寸初始化。

5. 样式要求
- 外框风格要轻量、干净，与“五健健康管理家长端H5”整体风格统一。
- 不要做复杂设备模型，不要加过重阴影。
- 可以增加一个小的听筒/摄像头装饰，但不要影响内容区域。

6. 验证重点
- 横屏手机外框尺寸正常，没有变形成网页宽屏。
- 签名画布不偏移。
- 鼠标或触摸落点与笔画一致。
- 点击确认签名后，能正常回到知情同意书页面并展示签名图片。
