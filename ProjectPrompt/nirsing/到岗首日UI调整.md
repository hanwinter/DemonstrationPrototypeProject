# Codex Prompt：优化首日服务档案移动端页面 UI

请基于项目已有移动端设计规范，对当前「首日服务档案」页面进行 UI 重构优化。

目标：

保持现有业务字段和功能逻辑不变，仅优化页面信息架构、布局、组件样式，使其符合《母婴移动端 Design System V1.0》。

---

# 一、整体页面规范

1. 页面保持移动端手机尺寸展示。

2. 页面高度固定，内容区域纵向滚动。

3. 滚动条样式保持项目统一移动端风格：

   * 细滚动条
   * 浅色背景
   * 圆角滑块
   * 不使用浏览器默认滚动条样式。

4. 页面整体采用：

```
顶部导航
↓
页面状态区域
↓
基础信息区域
↓
表单填写区域
↓
底部固定操作栏
```

不要通过大量卡片堆叠页面。

---

# 二、顶部区域优化

当前问题：

* “草稿”和“编辑”视觉风格不统一。
* 状态和操作混在一起。
* 视觉权重过高。

调整：

## 1. 页面标题区域

保持：

```
‹       首日服务档案        ...
```

---

## 2. 状态展示调整

删除：

* 草稿大卡片
* 编辑标签按钮

改为轻量状态展示：

示例：

```
首日服务档案

状态：草稿
```

要求：

* 状态文字小字号
* 使用浅色状态文字
* 不使用大面积标签背景
* 不占独立卡片区域

---

## 3. 服务人员和到岗日期调整

删除：

```
张洪霞·到岗日期2026-08-01
```

独立卡片。

改为基础信息：

```
服务人员：张洪霞
到岗日期：2026-08-01
```

放入订单基础信息区域。

---

# 三、订单信息区域优化

当前问题：

字段和值上下排列，占用高度过大。

修改为移动端信息展示模式。

## 字段和值同行

例如：

原：

```
客户

王女士

订单编号

DD202608060001
```

改为：

```
客户：王女士

订单编号：DD202608060001
```

---

## 短字段支持双列布局

例如：

```
客户：王女士        服务人员：张洪霞

订单编号：DD202608060001

服务周期：
2026-08-01 至 2026-08-14
```

规则：

* 字段名称固定宽度
* 冒号对齐
* 值区域自适应
* 不允许字段独占一整行

---

# 四、表单区域卡片重构

当前问题：

宝宝基本情况：

```
一个卡片
↓
宝宝1一个卡片
↓
字段一个区域
```

导致页面过长。

调整：

## 一个业务模块一个卡片

改为：

```
宝宝基本情况

宝宝数量

○ 单胎
○ 多胎


宝宝1

姓名：
输入框

性别：
○男 ○女

出生日期：
输入框
```

---

# 五、宝宝数量动态逻辑优化

默认：

```
宝宝数量

● 单胎
○ 多胎
```

默认选中单胎。

---

选择：

```
多胎
```

后：

增加：

```
宝宝数量：[ 2 ]
```

根据数量动态生成：

```
宝宝1

宝宝2

宝宝3
...
```

每个宝宝独立展示：

```
宝宝名称
性别
出生日期
体温
黄疸情况
```

---

# 六、单选按钮组件优化

当前问题：

* icon过小
* 黑色边框明显
* 不符合移动端视觉。

调整：

使用统一 Radio 组件。

要求：

* 直径 18-20px
* 无黑色粗边框
* 未选中状态浅灰
* 选中状态使用项目主题绿色
* 点击区域至少44px

示例：

```
● 单胎

○ 多胎
```

---

# 七、条件字段展示优化

重点优化：

黄疸、异常体征等条件字段。

当前：

```
黄疸

○无 ○有

黄疸值
趋势
```

修改为：

选择“有”后：

显示子区域：

```
黄疸

○ 无
● 有


┌─────────────┐
│ 黄疸信息    │
│             │
│ 黄疸值：
│ [    ]      │
│             │
│ 趋势：
│ ○消退 ○加重 │
└─────────────┘
```

要求：

所有二级字段：

* 缩进展示
* 浅色背景区域
* 与父字段形成明显层级

适用于：

* 黄疸
* 异常情况
* 特殊情况记录

---

# 八、输入框布局优化

当前问题：

所有字段：

```
字段名称

[输入框]
```

导致页面高度过长。

调整：

固定长度字段同行。

例如：

姓名：

```
宝宝姓名：[小雨]
```

体温：

```
体温：[36.5]℃
```

日期：

```
出生日期：[2026-07-25]
```

输入框宽度：

固定：

```
姓名：120px

日期：160px

数字：100px
```

禁止：

所有输入框 width:100%。

---

# 九、底部操作栏优化

保持固定底部。

按钮：

```
保存          提交
```

要求：

* 高度统一
* 圆角统一
* 与项目移动端按钮规范一致

保存：

* 白底
* 绿色边框

提交：

* 主题绿色填充

---

# 十、代码实现要求

1. 不新增页面。

2. 不修改业务字段。

3. 不改变数据逻辑。

4. 优先复用项目已有：

   * Card组件
   * Radio组件
   * Input组件
   * Button组件

5. 所有新增样式必须符合：

《母婴移动端 Design System V1.0》

避免生成新的视觉风格。

---

## 验收标准

完成后页面应达到：

* 页面高度明显减少
* 信息阅读类似移动端电子档案，而不是PC表单
* 状态、操作、信息三类元素视觉分离
* 一个业务模块一个卡片
* 条件字段有明显层级
* 输入效率提升
* 与母婴陪护小程序其他页面保持统一 UI 风格

---

这个提示词建议作为后续所有母婴移动端页面优化的基础 Prompt 模板，只替换业务模块名称和字段即可。
