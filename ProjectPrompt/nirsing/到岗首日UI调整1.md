# 四、优化 Radio 单选按钮样式

当前问题：

单选按钮：

* icon 太小。
* 选中状态有绿色填充 + 黑色边线。
* 视觉较重。

调整 Radio 样式：

要求：

1. 增大按钮尺寸。

```
radio直径：18px-20px
```

2. 去掉黑色边框。

3. 未选中：

```
○
```

使用浅灰色。

4. 选中：

```
●
```

使用主题绿色。

不要出现：

* 黑色描边
* 粗边框
* 外层阴影

5. 增大点击区域：

点击区域至少：

```
44px
```
