# Codex Prompt：优化首日服务档案条件字段展示布局

请继续优化「首日服务档案」页面中的条件字段展示区域。

本次只调整 UI 布局、字段排列方式、输入组件样式，不修改业务字段、不改变数据逻辑。

优化目标：

> 将当前“条件字段展开区域”从独立卡片模块改为紧凑型表单展开方式，提高移动端录入效率，减少页面高度。

# 一、删除「黄疸信息」「脐带信息」等二级标题

当前：

```text
黄疸

○ 无  ○ 有


┌─────────────┐
│ 黄疸信息    │
│             │
│ 黄疸值      │
│ 趋势        │
└─────────────┘
```

问题：

* “黄疸信息”没有实际业务含义。
* 增加视觉层级。
* 增加页面高度。

调整：

删除：

```
黄疸信息
脐带信息
```

等二级标题。

改为：

```
黄疸

○ 无       ● 有

    黄疸值：[46]

    趋势：
    ● 消退    ○ 加重
```

规则：

```text

```

```text

  趋势：
```

* 左侧缩进约16px。
* 不增加额外标题。
* 不增加新的卡片。

# 四、优化黄疸值输入框

当前问题：

数字输入框显示浏览器默认上下箭头。

修改：

黄疸值输入框：

禁止：

```html
type="number"
```

避免出现：

```
▲
▼
```

改为：

普通输入框：

支持：

* 数字输入；
* 数字校验。

例如：

```text
黄疸值：[46]
```

---

输入框要求：

* 宽度：80~100px。
* 高度与其他输入框一致。
* 不要占满整行。
