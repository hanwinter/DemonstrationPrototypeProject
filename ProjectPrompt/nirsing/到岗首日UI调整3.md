# 五、输入框宽度优化

当前问题：

姓名、日期等固定长度字段输入框占满整行。

例如当前：

```

[                 小雨                 ]
```

调整为：

```

```

输入框根据字段长度设置固定宽度。

调整：

| 字段  | 宽度       |
| --- | -------- |
| 姓名  | 120px    |
| 日期  | 150px    |
| 数字  | 80-100px |
| 手机号 | 160px    |

---

应用：

## 宝宝姓名

修改：


输入框：

约120px。
