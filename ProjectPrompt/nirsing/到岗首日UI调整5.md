# 一、优化多选/单选字段布局模式

当前问题：

例如：

```
现有传染病

      □ 无     □ 乙肝
      □ 梅毒   □ 其他
```

存在问题：

* 字段标题与选项区域分离；
* 多行选项时视觉关系弱；
* 标题不知道属于哪组选项。

---

## 调整为「标题列 + 选项列」布局

统一所有：

* 单选字段
* 多选字段

采用：

```text
字段标题       选项区域
```

示例：

## 现有传染病

调整为：

```
现有传染病    □ 无      □ 乙肝
              □ 梅毒    □ 其他
```

要求：

左侧：

* 固定标题区域宽度。

右侧：

* 选项区域自动换行。

不要：

* 标题单独占一整行；
* 选项整体向右偏移。

---

# 二、多行选项字段统一规则

适用于：

* 现有传染病
* 乳房情况
* 乳头情况
* 恶露量
* 恶露颜色
* 恶露气味
* 自然分娩会阴伤口

统一：

例如：

## 乳头情况

修改为：

```
乳头情况     ○ 正常      ○ 凹陷
             ○ 扁平
```

## 自然分娩会阴伤口

修改为：

```
自然分娩会阴伤口     □ 正常      □ 红肿
                    □ 渗出      □ 未知
```

要求：

* 第一行选项与字段标题垂直居中。
* 后续选项只在右侧区域换行。
* 不允许标题区域参与换行。

---

# 三、优化字段之间的视觉分割

当前问题：

多个字段连续排列：

```
现有传染病

乳房情况

乳头情况

恶露量
```

视觉连接弱。

调整：

增加字段之间轻量间距。

要求：

不要使用大卡片。

不要：

```
┌─────────┐
│字段     │
└─────────┘
```

推荐：

```
现有传染病    □ 无 □乙肝
              □梅毒 □其他


乳房情况      ○正常 ○硬块


乳头情况      ○正常 ○凹陷
```

通过：

* 上下间距；
* 浅色分隔线（可选）；

体现字段边界。

# 四、优化必填标识位置

当前问题：

必填标识：

* 与字段文字不垂直居中；
* 多行标题容易错位。

---

调整：

统一：

```
● 字段名称
```

结构。

要求：

* 红点和文字使用 flex 水平布局。
* 垂直居中。
* 红点尺寸固定。
* 不影响字段高度。

---

例如：

单行：

```
● 宝宝姓名
```

多行：

```
● 自然分娩会阴伤口
```

红点：

* 对齐第一行文字；
* 不居中整个多行区域。
