优化首日服务档案页面条件字段展示样式。

要求：

1. 删除条件展开区域的浅绿色背景块，不要使用嵌套卡片效果。
2. 黄疸、脐带等条件字段的二级内容改为“缩进展示”：
   
   示例：

   黄疸
   ○ 无    ● 有

       黄疸值：[5.8]

       趋势：
       ● 消退    ○ 加重


3. 二级字段通过：
   - 左侧缩进
   - 字段间距
   - 层级关系

   表达父子关系，不增加标题、不增加边框、不增加背景。

4. 所有条件展开字段统一此规则，包括：
   - 黄疸
   - 脐带
   - 眼部异常
   - 耳部异常
   - 鼻部异常
   - 口腔异常
   - 乳房异常

5. 保持现有字段、数据逻辑、交互逻辑不变，只调整 UI 布局和样式。

目标：
让页面更接近医疗护理记录风格，减少色块，提高信息阅读效率。
