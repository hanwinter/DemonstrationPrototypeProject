优化首日服务档案条件展开字段样式。

要求：

1. 黄疸、脐带等二级选项区域增加浅灰色背景容器，不使用边框，不使用卡片效果。
   - 背景：浅灰色
   - 圆角：8px
   - 内边距适当缩小

2. 二级字段统一采用“标题列 + 内容列”布局：

示例：

黄疸值 ●   [5.8]

趋势 ●     ○ 消退   ○ 加重


分泌物 ●   □ 无   □ 渗性
           □ 脓性

外观 ●     □ 干燥 □ 红肿
           □ 凸起


3. 二级区域内：
   - 字段标题固定宽度；
   - 所有字段左侧标题对齐；
   - 所有选项从统一位置开始；
   - 多行选项只在内容区域换行。

4. 保留必填标识在字段名称后方，并保证：
   - 与文字垂直居中；
   - 不影响布局。


5. 适用于所有条件展开字段：
   - 黄疸
   - 脐带
   - 眼部异常
   - 耳部异常
   - 鼻部异常
   - 口腔异常
   - 乳房异常

6. 不修改字段、不修改业务逻辑，只调整 UI 布局和样式。

目标：
让条件字段既有明确分组，又保持移动端医疗记录的简洁感。
