优化母婴陪护服务端底部 4 个 Tab 图标。

本次只调整底部导航 Icon 和选中状态，不修改页面布局和业务逻辑。

1. 底部导航保持：
- 首页
- 服务
- 消息
- 我的

2. 图标统一使用线性 Outline 风格，优先使用项目已有图标库；如果项目已有 Lucide / Iconify，直接复用，不要自绘。

推荐图标：
- 首页：Home
- 服务：Clipboard / ClipboardCheck / HandHeart，优先选择最简洁、最符合服务记录含义的一个
- 消息：MessageCircle
- 我的：UserRound / CircleUser

3. Icon 尺寸统一：
- 22px × 22px
- 线条粗细统一
- 不使用实心大图标
- 不使用渐变、3D、插画风

4. 未选中状态：
- Icon：#B8C0CC
- 文字：#9CA3AF
- 文字字号：12px

5. 选中状态：
- Icon：#F56B8A
- 文字：#F56B8A
- 不使用大面积胶囊背景
- 如需强调，可增加极浅粉色局部背景 #FFF1F5，但要轻量

6. Icon 与文字：
- 上下排列
- Icon 与文字间距约 4px
- 四个 Tab 水平均分
- 点击区域保持足够大

7. 当前页面属于“服务”模块时：
- “服务”图标和文字显示选中态
- 其他三个保持未选中态

8. 删除当前灰色方块占位图标。

目标：
底部导航呈现统一、轻量、现代的移动端 App 风格，与当前白色卡片 + 粉色主题保持一致。
