====================
三、字段结构
====================

请将乙肝感染孕产妇表单按以下分区实现。

一、基础信息

字段：
- 姓名
- 病历号
- 末次月经
- 预产期
- 孕产妇联系电话
- 主管医师

说明：
1. 姓名、病历号优先从 currentMother 带入。
2. 联系电话可从 currentMother 或当前 mock 数据带入。
3. 末次月经、预产期、主管医师可编辑。
4. 日期字段可以使用 el-date-picker，也可以保持当前项目中已有日期输入风格。

二、首次乙肝五项

字段：
- HBsAg
- 抗-HBs
- HBeAg
- 抗-HBe
- 抗-HBc
- 孕周
- 日期

要求：
1. 五项结果建议使用单选：
   阳性 / 阴性 / 未查
2. 默认值可参考纸质表单：
   HBsAg：阳性
   抗-HBs：阴性
   HBeAg：阴性
   抗-HBe：阳性
   抗-HBc：阳性
3. 孕周和日期为可编辑字段。

三、HBV DNA 复查

标题：
HBV DNA（每两月复查）

字段建议：
- 复查记录列表
- 每条记录包含：
  - 检查日期
  - 孕周
  - HBV DNA 结果
  - 备注

要求：
1. 至少展示 3 行空白复查记录，模拟纸质表单多行填写。
2. 如果实现方便，可以提供“新增一行”按钮。
3. UI 不要复杂，保持医疗文书表格/横线录入风格。

四、肝功能检测复查

标题：
肝功能检测（每两月复查）

字段建议：
- 复查记录列表
- 每条记录包含：
  - 检查日期
  - 孕周
  - ALT
  - AST
  - TBIL
  - 备注

要求：
1. 至少展示 3 行空白复查记录。
2. 如果实现方便，可以提供“新增一行”按钮。
3. 保持与 HBV DNA 复查区一致的 UI。

五、抗病毒治疗

标题：
抗病毒治疗

提示说明：
HBV DNA ≥ 2×10^5 IU/mL，应于孕 28 周采取抗病毒治疗。

字段：
- 是否抗病毒治疗：是 / 否
- 开始孕周
- 开始日期
- 用药名称
- 治疗记录/备注

要求：
1. 提示说明可以放在分区标题下方，以浅色小字显示。
2. 不要做强烈警告样式。
3. 治疗记录/备注使用 textarea。

六、转诊外院建档产检分娩

字段：
- 转诊孕周
- 转诊日期
- 使用转诊单进行转诊：是 / 否
- 使用转诊知情同意书：是 / 否
- 已明确追访病人在外院建档产检
- 和外院沟通确定
- 收到外院转诊单回执

要求：
1. “是/否”字段使用 radio。
2. 最后三项可以使用 checkbox。
3. 分区标题和字段排版要与危重孕产妇转会诊申请单保持一致。

七、新生儿及出院随访

字段：
- 新生儿球蛋白及乙肝疫苗接种情况
- 发放出院指导：是 / 否
- 是否为高暴露需要医疗机构追访：是 / 否

要求：
1. 接种情况使用 textarea 或较长输入框。
2. 是/否字段使用 radio。
3. 字段名称尽量使用纸质表单原文。
