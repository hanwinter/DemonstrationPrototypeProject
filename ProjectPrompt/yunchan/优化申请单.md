====================

当前页面路径：
/maternal/report-forms

孕产保健系统 / 危重孕产妇上报单据

当前页面实现存在业务定位问题：
页面现在像“多个孕妇的危重孕产妇转会诊申请单列表”，表格中 mock 了王某某、李某某、赵某某等多个孕妇。

该页面从“某一个孕妇档案”进入，是当前孕妇档案下的业务单据管理页。

因此，页面列表中不应该展示多个孕妇，而应该展示“当前孕妇名下的多种单据”。

====================
四、数据结构建议
====================

请不要继续把 records 理解为 referral records。

建议改为：
documentTypes + documents

documentTypes 用来定义单据类型，例如：
- critical_referral
- syphilis_pregnancy
- hepatitis_b_pregnancy

documents 表示当前孕妇名下的单据实例。

每条 document 建议包含：
- id
- type
- documentNo
- diagnosisOrSummary
- status
- updatedAt
- printedAt
- formData

危重孕产妇转会诊申请单可以继续复用现有 createEmptyReferral / createDemoReferral 的数据结构，不要大幅删除现有字段。

梅毒、乙肝两类单据本次先做占位表单，不需要完整医学字段。

====================
七、状态与按钮文案
====================

不再使用：
- 草稿
- 已提交

统一改为：
- 未完成
- 待打印
- 已打印
- 已作废

表单底部按钮改为：
- 取消
- 临时保存
- 保存申请单
- 保存并打印

状态规则：
1. 点击“临时保存”
   状态设置为：未完成
   返回列表
2. 点击“保存申请单”
   状态设置为：待打印
   返回列表
3. 点击“保存并打印”
   状态设置为：已打印
   设置打印时间
   返回列表
4. 点击列表中的“打印”
   状态设置为：已打印
   设置打印时间
5. 不要直接删除医疗单据。
   将“删除”改为“作废”。
   作废后状态设置为：已作废。
