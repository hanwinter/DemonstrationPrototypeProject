====================
一、调整背景
====================

当前页面：
/maternal/report-forms

页面名称：
孕产相关单据

该页面已经从“多个孕妇列表”调整为“单个孕妇档案下的多类型单据列表”。

但当前 UI 风格与孕产保健系统已确定的医疗文书风格不一致。

参考风格：
以之前“新建危重孕产妇转会诊申请单”页面为准。

目标风格关键词：
- 医疗文书感
- 白底
- 细边框
- 紧凑
- 少装饰
- 表单化
- 不要后台管理卡片感
- 不要大面积灰底卡片分层

====================
二、页面整体布局
====================

当前页面不要保持“面包屑卡片 + 内容卡片”两个独立块的后台布局。

请调整为类似医疗文书页面的整体白色容器：

1. 页面主体使用一个白色大容器。
2. 容器外层使用浅灰蓝细边框。
3. 面包屑、标题、当前孕妇信息、表格都放在同一个白色容器中。
4. 页面左右留白适当缩小，整体宽度可接近当前内容宽度，但不要显得像居中的后台卡片。
5. 背景可以保留浅灰，但视觉重点应是白色文书容器。
6. 不要增加圆角卡片、阴影、渐变、装饰图形。

====================
三、顶部标题区
====================

顶部结构建议按以下顺序：

第一行：
孕产保健系统 / 孕产妇档案 / 孕产相关单据

第二行：
孕产相关单据

右侧保留：
+ 新建单据

第三行：
当前孕妇：王某某，31岁，35+2周，病历号 M20260805001 ｜ 身份证号：110101199503081234 ｜ 联系电话：13800000000 ｜ 高危因素/主要诊断：妊娠期高血压疾病

注意：
1. 不建议继续把“王某某 - 孕产相关单据”作为大标题。
2. 主标题建议为“孕产相关单据”。
3. 当前孕妇信息以纯文本信息行展示，重点字段可加粗。
4. 不要把孕妇信息条做成明显的卡片或表格。
5. 信息行可以有上边框或下边框，但要轻，不要厚重。

====================
四、新建按钮样式
====================

“新建单据”按钮保留在标题区右侧。

要求：
1. 按钮可以是蓝色主按钮，但尺寸不要过大。
2. 文案为：
   + 新建单据
3. 保持 Element Plus 基础风格即可。
4. 不要增加额外说明文字。

====================
五、表格 UI 调整
====================

表格需要更接近医疗业务表格，而不是后台管理卡片。

表格样式建议：
1. 表格外边框使用浅灰蓝细线。
2. 表头背景使用白色或非常浅的灰蓝色。
3. 表头文字颜色克制，不要过重。
4. 行高适当收紧。
5. 字号控制在 13px 左右。
6. 单元格左右 padding 不要太大。
7. 状态标签可以保留，但颜色要克制。
8. 表格上方不要增加额外卡片标题区。
9. 表格下方如果没有分页，不要强行留分页区域。

当前表格列保持现有业务结构：
- 序号
- 单据类型
- 单据编号
- 主要诊断/说明
- 状态
- 最近填写时间
- 打印时间
- 操作

不要因为 UI 调整改变列含义。

====================
六、操作按钮调整
====================

操作列中的按钮不要使用 icon。

请移除操作按钮中的图标，只保留文字按钮。

例如：

待打印：
查看  修改  打印  更多

未完成：
继续填写  作废

已打印：
查看  修改  重新打印  更多

已作废：
查看

要求：
1. 不要在操作列显示眼睛、铅笔、打印机、更多等图标。
2. 操作按钮使用纯文字 link button。
3. 按钮之间保持适当间距。
4. 如果操作过多，可以保留“更多”文字按钮或文字下拉，不要用图标。
5. “作废”使用危险色文字，但不要过度醒目。
6. 不要改动操作对应的业务逻辑。
