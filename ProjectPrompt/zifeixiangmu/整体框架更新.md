# 一、核心业务逻辑调整

请按以下业务逻辑重构页面内容：

1. 系统中不再区分“免费项目库”和“自费项目库”。
2. 所有可执行检查都统一来自“体检项目库”。
3. 体检项目本身可以有标准价格。
4. 某个项目在某次体检中是免费、收费、折扣、统一结算，是“体检批次配置”的属性。
5. 体检批次对应一次五健入校筛查批次。
6. 家长端 H5 页面会展示：
   - 本批次体检项目：只读展示，说明本次入校筛查包含哪些项目。
   - 推荐加项项目：类似商城模块，家长可选购，选购后需要支付。
7. 家长单独选购的推荐加项项目会生成收费订单和支付流水。
8. 后台收费/退费订单只针对家长单独选购的项目，不针对批次内默认项目。
9. 最终体检执行订单由：
   - 批次内体检项目
   - 家长已支付的推荐加项项目
   合并生成。

业务流程：

体检项目库
→ 体检批次配置
→ 家长端展示本批次体检项目
→ 家长选购推荐加项项目
→ 生成收费订单
→ 微信支付
→ 批次项目 + 已支付加项项目
→ 生成最终体检执行订单

## 12.1 本次体检项目

标题：

本次体检项目

说明：

以下项目为本次学校统一安排的五健入校筛查内容。

展示：

- 身高测量
- 体重测量
- 血常规
- 口腔检查

该区域只读，不提供勾选和支付按钮。


## 12.2 推荐加项

标题：

推荐加项

说明：

以下项目可由家长自愿选择，选择后需在线支付。

展示：

- 血脂检查 ¥30
- 维生素D检测 ¥55
- 骨龄检测 ¥80

推荐加项可选择，加入订单后进入微信支付流程。


# 十三、统一删除和替换文案

全局检查当前收费模块页面。

删除以下文案：

- 关联免费项目
- 关联基础体检项目
- 自费项目合并到免费项目
- 免费项目 / 自费项目作为父子关系

替换为：

- 体检项目库
- 批次内项目
- 推荐加项
- 家长选购加项
- 最终体检执行项目
- 体检执行订单


# 十四、最终检查

完成后检查：

1. 不再出现“关联免费项目”字段。
2. 体检项目库中项目本身有标准价格。
3. 体检批次配置中分为“批次内项目”和“推荐加项项目”。
4. 批次内项目不生成家长单独支付订单。
5. 推荐加项项目由家长选择后生成收费订单。
6. 自费订单管理只展示家长选购加项订单。
7. 支付管理只展示家长选购加项支付流水。
8. 体检项目合并管理展示“批次内项目 + 已支付加项 = 最终执行项目”。
9. 执行订单详情中按执行环节分组展示项目。
10. 整体页面风格保持当前五健后台风格。
