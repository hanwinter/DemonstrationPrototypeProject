请调整当前“演示项目”首页 UI。

本次调整**只修改首页的布局与导航展示方式，不修改任何现有演示页面、路由地址、页面功能和业务逻辑**。

## 一、调整目标

当前首页采用“大模块卡片 + 功能小卡片”的形式，随着演示页面增加，卡片数量越来越多，页面层级复杂、视觉较乱。

本次首页改为简洁的**一级系统 + 二级页面入口**结构。

核心原则：

* 不使用系统大卡片
* 不使用功能小卡片
* 不使用 Icon
* 不显示页面说明文字
* 一级展示系统名称
* 二级直接展示该系统下的页面入口
* 强调导航效率，不做产品宣传式设计
* 保留现有所有页面入口和跳转逻辑

---

## 二、首页一级结构

首页保留以下四个一级系统：

1. 孕产保健系统
2. 五健系统
3. 母婴陪护
4. 单页面演示

四个系统统一按照**从上到下的纵向文档流**排列。

不要再采用当前：

“左侧宽模块 + 右侧窄模块”

这种不规则布局。

所有一级系统使用完全一致的结构和样式。

---

## 三、一级系统标题

每个系统顶部展示：

```text
孕产保健系统                                      8 项
────────────────────────────────────────────────────
```

要求：

* 左侧：系统名称
* 右侧：该系统页面数量
* 系统名称字号约 18～20px
* font-weight: 600
* 数量使用较小的灰色文字
* 不使用蓝色强调数量
* 不显示 Icon
* 不显示 Badge
* 不显示系统介绍文字
* 标题下增加一条浅色分割线
* 四个系统标题样式完全统一

页面数量根据当前实际入口数量显示。

---

## 四、二级页面入口

系统标题下面直接展示当前系统已有页面。

例如：

```text
孕产保健系统                                      8 项
────────────────────────────────────────────────────

外院报告 OCR 识别             →    外院报告影像管理             →
外院报告影像 v1.0             →    电子产程图                   →
知情同意书管理                →    档案补录工作台               →
患者企微关联管理              →    危重孕产妇上报单据           →
```

### 二级入口样式

取消当前所有功能卡片样式：

* 不要独立白色卡片
* 不要边框
* 不要阴影
* 不要圆角卡片
* 不要功能说明小字
* 不要 Icon

每个入口只保留：

```text
页面名称                                    →
```

页面名称为主要信息。

右侧保留轻量箭头，用于表达可以进入页面。

---

## 五、二级入口布局

桌面端默认采用 **2 列 Grid**。

例如：

```text
grid-template-columns: repeat(2, minmax(0, 1fr));
```

两列宽度一致。

每个入口需要有足够的横向和纵向留白，不要因为取消卡片以后让文字挤在一起。

建议：

* 单个入口高度约 42～48px
* 页面名称与箭头垂直居中
* 两列之间保留合理间距
* 同一列页面名称左侧统一对齐
* 箭头统一靠右
* 不同入口之间可以使用留白区分，不需要增加明显边框

页面名称较长时优先保证完整显示，不要为了做三列而压缩文字。

因此本页面桌面端固定优先使用 **2 列，而不是 3 列**。

---

## 六、Hover 交互

默认状态保持极简。

鼠标 Hover 到某个二级入口时，可以提供轻微反馈，例如：

* 页面名称变为主题蓝色
* 箭头变为主题蓝色
* 或整行出现非常浅的蓝灰色背景

注意：

Hover 背景只能作为交互反馈，不能让默认状态重新呈现“卡片”效果。

不要：

* 明显边框
* 明显阴影
* 大面积蓝色背景
* 明显位移动画

可以增加非常轻微的 `transition`。

---

## 七、整体页面布局

页面整体保留当前项目已有的浅灰蓝背景风格。

但内容区域不要再拆成四张独立白色大卡片。

建议使用：

```text
页面浅灰蓝背景

        ┌──────────────────────────────────────────┐
        │                                          │
        │  演示项目                                │
        │                                          │
        │  孕产保健系统                      8 项   │
        │  ─────────────────────────────────────   │
        │  页面入口        →    页面入口        → │
        │  页面入口        →    页面入口        → │
        │                                          │
        │  五健系统                          5 项   │
        │  ─────────────────────────────────────   │
        │  页面入口        →    页面入口        → │
        │                                          │
        │  母婴陪护                          5 项   │
        │  ─────────────────────────────────────   │
        │  页面入口        →    页面入口        → │
        │                                          │
        │  单页面演示                        1 项   │
        │  ─────────────────────────────────────   │
        │  单页面演示      →                       │
        │                                          │
        └──────────────────────────────────────────┘
```

整个内容区域可以使用一个统一的白色主体容器。

主体容器：

* 居中展示
* 设置合理 `max-width`
* 与浏览器左右保持充足留白
* 可以使用非常轻的圆角
* 可以保留非常轻的边框或阴影
* 不要再嵌套多层卡片

---

## 八、系统之间的间距

不同一级系统之间主要依靠留白形成分组。

建议：

```text
一级标题
分割线

二级入口
二级入口

        ← 较明显纵向留白 →

下一个一级标题
分割线
```

一级系统之间的距离明显大于二级入口之间的距离，从视觉上自然形成：

**一级系统 > 二级页面**

不要使用粗分割线或者大面积不同背景色来划分系统。

---

## 九、页面顶部

首页顶部增加或保留简单标题：

```text
演示项目
```

标题只承担页面名称作用。

不要增加：

* 大 Banner
* 欢迎语
* 数据统计卡片
* 系统说明
* 渐变背景
* 装饰 Icon

首页定位就是一个**简洁、高效的 Demo 页面导航目录**。

## 十二、最终视觉要求

整体风格关键词：

**简洁、克制、清晰、目录化、低装饰、强层级。**

最终页面应该更接近一个经过设计的：

> **“演示项目功能目录”**

而不是：

> “业务系统卡片 Dashboard”。

重点通过：

**字号层级 + 对齐 + 留白 + 分割线 + Hover**

建立视觉秩序，不再依赖大量卡片、Icon、背景色和说明文字。

修改完成后，请同时检查：

1. 四个一级系统视觉结构是否完全统一；
2. 所有原有页面入口是否保留；
3. 原有路由是否保持不变；
4. 是否彻底移除了原有大卡片、小卡片和 Icon；
5. 页面名称较长时是否仍然排版稳定；
6. 页面增加新的二级入口后是否可以自然向下扩展；
7. 桌面端和窄屏下是否均不存在横向溢出。
