# 1. 设计原则

## 1.1 核心设计理念

母婴服务移动端不是后台管理系统，而是：

> 服务人员日常工作的数字化工具。

因此：

优先级：

```
信息阅读效率
>
操作效率
>
视觉装饰
```

避免：

- 复杂后台表格风格；
    
- 过度卡片化；
    
- 大量输入框；
    
- 信息密度过低。
    

---

# 2. 页面整体结构规范

所有移动端页面统一：

```
手机容器

┌─────────────┐
│ 顶部导航栏   │ 固定
├─────────────┤
│             │
│ 内容区域     │ 滚动
│             │
├─────────────┤
│ 底部Tab导航 │ 固定
└─────────────┘
```

要求：

- 手机高度固定；
    
- 禁止整个页面滚动；
    
- 内容区域独立滚动；
    
- 顶部和底部固定。

# 母婴移动端 Design System V1.0

## 表单与信息展示规范（新增）

## 1. 页面顶部状态区域规范

### 问题

当前：

```
[草稿]        [编辑]
张洪霞 · 到岗日期2026-08-01
```

存在问题：

- 草稿是状态，编辑是操作，两者不属于同一视觉类型
    
- 状态标签过重，占用页面空间
    
- 服务人员、日期属于基础信息，不应该单独形成卡片
    

---

### 规范要求

### 1.1 页面状态统一采用轻量状态栏

适用于：

- 草稿
    
- 已保存
    
- 已提交
    
- 已审核
    
- 已完成
    

展示方式：

```
首日服务档案

状态：草稿
```

或者：

```
首日服务档案   草稿
```

规则：

- 状态使用小号文字或轻量Tag
    
- 不使用大面积背景
    
- 不单独占用卡片
    
- 不与按钮混排
    

示例：

```
首日服务档案              草稿

张洪霞 · 到岗日期 2026-08-01
```

---

### 1.2 操作按钮规范

编辑、保存、提交属于操作。

禁止：

```
草稿      编辑
```

使用：

```
右上角：
··· 更多

底部：
保存       提交
```

或者：

```
编辑模式：
取消     保存
```

规则：

- 状态 ≠ 操作
    
- 操作按钮不能使用状态标签样式
    

---

# 2. 移动端基础信息展示规范

```
2026-08-01 至 2026-08-14
```

---

## 2.2 短字段支持双列布局

当字段值长度较短：

使用：

```
客户：王女士       性别：女

订单编号：DD001    宝宝数量：单胎
```

适用：

|字段|布局|
|---|---|
|姓名|同行|
|性别|同行|
|电话|同行|
|日期|同行|
|编号|单独|

---

规则：

- 字段名宽度固定
    
- 值区域自适应
    
- 不允许每个字段独占一行

# 3. 卡片使用规范

## 3.1 信息填写禁止过度拆卡

当前：

```
宝宝基本情况
↓
宝宝1
↓
宝宝性别
↓
宝宝日期
```

大量卡片造成：

- 页面过长
    
- 信息割裂
    
- 用户填写路径复杂
    

---

规范：

一个业务模块一个卡片。

例如：

```
宝宝基本情况

宝宝数量

○ 单胎
○ 多胎


宝宝1

姓名：小雨

性别：男

出生日期：2026-07-25

体温：36.5℃
```

---

## 3.2 卡片层级

推荐：

```
页面

 └── 模块卡片
       ├── 标题
       ├── 字段组
       └── 子区域
```

禁止：

```
页面

 └── 卡片
       └── 卡片
             └── 卡片
```

---

# 4. 动态字段展示规范

## 4.1 条件字段必须视觉分组

例如：

黄疸：

当前：

```
黄疸
○ 无   ○ 有

黄疸值
黄疸趋势
```

视觉关系弱。

---

规范：

选择后展开子区域：

```
黄疸

○ 无
● 有


┌─────────────┐
│ 黄疸信息    │
│             │
│ 黄疸值：
│ [   ] mg/dl │
│             │
│ 趋势：
│ ○ 消退 ○ 加重
└─────────────┘
```

---

规则：

所有条件显示字段：

- 使用缩进
    
- 使用浅色背景区域
    
- 增加顶部间距
    
- 明确属于父字段
    

适用：

- 黄疸
    
- 异常体征
    
- 疾病史
    
- 过敏史
    
- 特殊情况
