## 一、新增模块入口

在当前系统左侧主导航中新增一级菜单：

**单页面演示**

该模块用于承载后续多个独立演示页面，不与正式业务菜单结构强绑定。

菜单结构先设计为：

* 单页面演示

  * 体检数据

后续还会继续增加其他页面，因此“单页面演示”需要设计为可扩展的父级菜单，不要把“体检数据”直接作为一级菜单。

要求：

1. 点击“单页面演示”可展开/收起子菜单。
2. 当前先增加一个子菜单“体检数据”。
3. 后续新增其他演示页面时，可以直接在该模块下继续增加二级菜单。
4. 不修改现有正式业务模块的菜单结构和路由。
5. 不影响现有页面功能。
6. 新增独立路由，避免复用正式“体检管理”中的原页面路由。
7. 页面整体仍使用当前项目已有框架、顶部栏、左侧导航和基础组件。

# 三、整体 UI 风格

页面不要继续使用明显的现代 SaaS 后台设计风格。

整体要求：

* 去掉大面积渐变背景。
* 去掉明显卡片化设计。
* 减少大圆角。
* 减少大面积主题色。
* 不使用明显阴影。
* 不使用大字号标题。
* 提高页面信息密度。
* 所有控件整体压缩。
* 以“查询条件 + 工具栏 + Grid 表格 + 分页”为页面主体。

推荐颜色：

* 页面背景：`#F5F6F7`
* 查询区域：`#F7F9FB`
* 工具栏：`#FFFFFF`
* 表头：`#EEEEEE` 或 `#F1F1F1`
* 表格边框：`#D8D8D8`
* 主文字：`#333333`
* 次级文字：`#666666`
* 浅蓝辅助色：`#DCEBFA`
* 主蓝可以保留，但降低饱和度，不要使用高饱和青绿色。
