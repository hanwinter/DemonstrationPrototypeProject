# 十三、父子选择逻辑

必须实现项目分组的父子级勾选逻辑。

例如：

```text
☑ 牙位及牙齿数量
   ☑ 牙位图
   ☑ 牙齿数量
   ☑ 龋齿（坏牙）数
   ☑ 缺失数量
   ...
```

规则：

1. 勾选父级 → 当前组所有子项目全部勾选；
2. 取消父级 → 当前组子项目全部取消；
3. 子项目只选一部分 → 父级显示半选状态；
4. 子项目全部选中 → 父级自动变为选中；
5. 子项目全部取消 → 父级自动取消。

顶部“全选/反选”则作用于当前分类内所有项目。
