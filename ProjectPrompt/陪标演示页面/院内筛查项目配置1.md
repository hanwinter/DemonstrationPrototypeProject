# 四、项目配置改成“双栏选择器”

这是本次最重要的改动。

分类页签下方不要再平铺大量 Checkbox。

改成：

**左侧“可选项目” + 中间操作 + 右侧“报告已选项目”**

结构：

```text
┌─────────────────────────┐       ┌────┐       ┌─────────────────────────┐
│ 可选项目                 │       │ >  │       │ 已选报告项目             │
│ 搜索 [______________]    │       │ >> │       │ 已选 8 项                │
├─────────────────────────┤       │ <  │       ├─────────────────────────┤
│ □ 牙位图        KQ01001  │       │ << │       │ 1 牙位图        KQ01001  │
│ □ 牙齿数量      KQ01002  │       └────┘       │ 2 牙齿数量      KQ01002  │
│ □ 龋齿数        KQ01003  │                    │ 3 龋齿数        KQ01003  │
│ □ 缺失数量      KQ01004  │                    │ 4 缺失数量      KQ01004  │
│ □ 填充数量      KQ01005  │                    │ 5 填充数量      KQ01005  │
│ ……                       │                    │ ……                       │
└─────────────────────────┘                    └─────────────────────────┘
```

左右宽度约：

* 可选项目：42%
* 中间操作：6%
* 已选项目：42%

剩余空间用于边距。

# 八、增加“报告展示顺序”概念

右侧项目顺序就是最终报告展示顺序。

必须支持调整。

推荐采用：

**上移 / 下移**

不要强制做现代拖拽排序。

规则：

* 第一项点击“上移”无效；
* 最后一项点击“下移”无效；
* 移动后序号自动重新排列；
* 切换分类后保持已配置顺序；
* 保存后保持当前顺序。
