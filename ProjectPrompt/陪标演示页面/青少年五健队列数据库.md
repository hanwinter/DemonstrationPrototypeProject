请在当前五健系统前端演示项目的：

**单页面演示**

模块下新增：

**青少年五健队列数据库**

本页面用于展示系统针对不同健康问题和风险等级，将学生纳入长期健康管理队列并持续跟踪的能力。

页面核心不是“学生名单”，而是：

> 按健康问题和风险等级建立动态管理人群。

---

# 一、菜单新增

单页面演示新增：

* 青少年五健队列数据库

使用独立路由。

---

# 二、页面定位

核心能力：

1. 建立五健专项健康队列；
2. 按风险等级分类；
3. 查看队列人数变化；
4. 查看学生干预状态；
5. 跟踪复筛、随访和干预效果；
6. 支持跨学校、区域人群分析。

---

# 三、整体布局

不要使用普通：

> 查询条件 + 学生大表格

改成：

> 左侧队列目录 + 中间队列概览 + 下方人员管理

结构：

```text
青少年五健队列数据库

左侧队列目录        右侧当前队列

视力健康            队列概况
口腔健康            风险分布
体重健康            管理进展
脊柱健康
心理健康            队列成员
```

左侧约 220px。

---

# 四、左侧队列目录

一级分类：

* 视力健康
* 口腔健康
* 体重健康
* 脊柱健康
* 心理健康

每个专项下面配置队列。

例如视力：

```text
近视高风险队列        1260人
视力下降队列          850人
高度近视重点队列      120人
```

体重：

```text
超重队列
肥胖队列
重度肥胖重点队列
```

心理：

```text
心理关注队列
高风险心理队列
持续干预队列
```

点击队列切换右侧数据。

# 五、当前队列概况

显示：


采用紧凑指标条。

# 六、队列规则

增加：

**入队规则**

显示：

```text
所属专项：视力健康
风险等级：高风险
入队条件：
- 裸眼视力异常
- 远视储备不足
- 屈光状态达到风险阈值

退出条件：
- 连续两次复查恢复正常
- 医生确认结束管理
```

只读展示即可。

右上角：

**配置规则**

打开独立配置页或小弹窗。

---

# 七、风险分布

展示：

* 一般风险
* 中风险
* 高风险
* 重点风险

使用横向条形图或简单柱状图。

不要大饼图。

# 十、管理记录

点击：

**管理记录**

进入二级页面。

展示某学生在当前队列中的全过程：

```text
2026-04-10
筛查发现视力异常
加入近视高风险队列

2026-04-18
完成复筛
风险等级：高风险

2026-05-02
人工随访
家长已知晓

2026-06-18
复查
指标有所改善
```

采用年份/日期记录列表。

# 十一、干预效果

右侧增加：

**队列干预效果**

* 稳定人数
* 风险升级人数
* 退出队列人数

可按：

* 学校

查看人数。

```text
西湖区  326人
拱墅区  285人

```

页面上方增加小型提示：


---

# 十四、视觉要求

继续使用：

* 浅蓝灰
* 白底
* 紧凑
* 高信息密度
* 医疗业务后台

不要做科研数据库风格。

不要把页面命名理解成 SQL 数据库管理工具。

---

# 十五、最终目标

页面要让用户理解：

系统可以把五健筛查发现的风险学生形成长期管理人群，

并持续记录：

**发现 → 入队 → 复筛 → 随访 → 干预 → 评价 → 退出**

实现从一次筛查向长期健康管理转变。
